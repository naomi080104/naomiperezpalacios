México Místico

México Místico es una propuesta de diseño web para una agencia ficticia especializada en recorridos a destinos relacionados con el esoterismo mexicano.
La plataforma combina contenido informativo sobre la historia, cultura y simbolismo de diversos pueblos con un sistema para explorar destinos y agendar excursiones. El objetivo fue crear una interfaz atractiva, intuitiva y coherente con la identidad temática del proyecto.
